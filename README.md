# פאזל החשבון (Math Puzzle)

A tiny local math puzzle game (Hebrew UI) that helps a 7-year-old practice additions.

## איך משחקים
- הלוח מכוסה במשושים צבעוניים. כל צבע הוא רמת קושי:
  - 🟢 קל — שני מספרים בין 1 ל־9
  - 🔵 בינוני — מספר ראשון 1–20, שני 1–10
  - 🟠 קשה — מספר ראשון 1–80, שני 1–20
  - 🔴 אתגר — שני מספרים גדולים מ־20, שהסכום שלהם עד 100
- המשושים הקשים במרכז, הקלים בשוליים.
- לוחצים על משושה → מופיע תרגיל ולוח מספרים על המסך.
- תשובה נכונה → המשושה נעלם וחושף חלק מהתמונה.
- תשובה שגויה → המשושה מהבהב באדום. אפשר לנסות שוב או ללחוץ "סגור וחזור ללוח" ולנסות משושה אחר.
- מנצחים כשמגלים את כל התמונה 🎉

## הפעלה
פשוט לחצו-פעמיים על `index.html` – זה עובד ישירות בדפדפן, בלי שרת.

## הוספת תמונות
1. הכניסו קבצי תמונות (JPG/PNG/WebP וכו') לתיקייה `Images/`. מומלץ ביחס 1:1.
2. פתחו את `Images/manifest.js` והוסיפו את שמות הקבצים לרשימה:
   ```js
   window.IMAGE_MANIFEST = [
       "cat.jpg",
       "family.png",
       "vacation.webp",
   ];
   ```
3. בכל משחק חדש יש 50% סיכוי לתמונה מהתיקייה ו־50% סיכוי לאימוג'י אקראי.

אם הרשימה ריקה — משתמשים תמיד באימוג'י אקראי.

## מבנה
- `index.html` — HTML + מבנה הדף
- `style.css` — עיצוב
- `game.js` — לוגיקת המשחק (רינדור משושים, שאלות, ניקוד)
- `Images/` — התמונות שלך + `manifest.json`
